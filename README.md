# sky

Release binaries of sky, a command-line tool that scaffolds, deploys and runs Telegram bot projects.

The source code is private. This repository holds only the published releases: one binary per platform
(macOS and Linux, amd64 and arm64) and a `SHA256SUMS` file signed with Ed25519. The installer and `sky update`
check that signature before they install anything.

The install command and the license are on https://sky-cli.ru.
